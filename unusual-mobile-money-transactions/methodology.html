Machine Learning Pipeline & Methodology

A breakdown of the unsupervised data processing workflow, normalization standards, and algorithm mechanics.

1. Data Preprocessing & Feature Engineering

Transaction types (TRANSFER, CASH_OUT, PAYMENT, DEPOSIT) were converted using One-Hot Encoding. Features were scaled using StandardScaler to ensure features like transaction amounts do not overshadow lower-range balance features.

2. Isolation Forest Model

Isolates anomalous data points by constructing random decision trees. Anomalies require fewer partitions to isolate than normal data due to their unique positions in feature space.

3. K-Means Distance Scoring

Partitions data into optimal clusters ($k=4$). Computes Euclidean distance from each sample point to its assigned centroid; points exceeding the 95th percentile distance are flagged as anomalies.

Model Configuration Specifications

Component Configuration / Parameter Purpose
Scaler StandardScaler() Standardizes features by removing mean and scaling to unit variance.
Isolation Forest contamination=0.05, n_estimators=100 Sets expected proportion of outliers in the dataset to 5%.
K-Means Clustering n_clusters=4, n_init=10 Groups typical transaction behavior into 4 baseline operational profiles.
Dimensionality Reduction PCA(n_components=2) Projects multi-dimensional feature space onto 2D plane for visual analysis.
