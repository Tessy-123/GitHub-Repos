Unusual Mobile Money Transactions Detection

An Unsupervised Machine Learning Framework leveraging Isolation Forest and K-Means Distance Clustering to discover non-standard behavioral patterns and fraud anomalies in real-time mobile transactions.

Objective

Detect financial transactions that deviate significantly from typical user baselines without relying on pre-labeled training data, mitigating unseen fraud vectors.

ML Algorithms

Implementation of Isolation Forest (tree-based isolation) and distance-driven K-Means Clustering for multidimensional outlier scoring.

Primary Deliverable

A production-ready pipeline that outputs risk-scored anomaly flags, feature scaling parameters, and visual dimensional projections (PCA).
